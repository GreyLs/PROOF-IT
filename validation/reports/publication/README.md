# Проверки копии для GitHub

`cpu-tests.xml` — фактический JUnit-протокол 417 CPU-проверок. `checks.json` фиксирует результаты выполненных Rust, веб- и Node-команд. `repository-audit.json` содержит результат проверки файлов, PDF, ссылок и известных рабочих секретов. `source-manifest.json` связывает публикуемые файлы с их точными SHA-256.

18 Rust-тестов прошли; один тест с реальной локальной языковой моделью явно пропущен. Веб-сборка и 13 Node-проверок прошли. Сохраняется предупреждение о размере основного JavaScript bundle.

HTTP/браузерные и нагрузочные испытания здесь не запускались повторно. Исходные протоколы в `../current/` сохраняют собственные даты, области проверки и manifest исходного инженерного среза. Изменения публикации отражены отдельным manifest, поэтому новый README и CI не выдаются за исходную версию измерений.
