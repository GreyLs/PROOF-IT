# Снимки интерфейса

## Галерея README

Восемь новых PNG находятся в [`assets/screenshots/`](assets/screenshots/). Съёмка выполнена 11 октября 2026 года в Chromium с работающего демонстрационного приложения. Старые изображения при подготовке галереи не использовались. Ответы API и содержимое DOM не подменялись; кадры не ретушировались.

| Кадр | Роль и состояние | Что проверялось перед съёмкой |
|---|---|---|
| [01 · Вход](assets/screenshots/01-login.png) | Без сессии | Текущий заголовок, загрузка видео, форма входа |
| [02 · Резюме](assets/screenshots/02-resume.png) | Кандидат; тест подготовлен | Отдельная цель, стек, зарплата, ожидание допуска |

| [05 · Двойник](assets/screenshots/05-digital-twin.png) | Кандидат; расчёт завершён | Две группы результатов, реальное задание CPU, модельные диапазоны |

| [08 · Телефон](assets/screenshots/08-candidate-offer-mobile.png) | Кандидат; предложение получено | Те же условия, действия принять/отклонить, отсутствие горизонтального переполнения |

Демонстрационные пользователь, компания, резюме, вакансия и предложение создаются отдельно, получают признак `synthetic` и удаляются по своим точным ID после съёмки. Реальные аккаунты и их данные не используются. Для графа и подбора проводится контролируемый прогон проверки знаний через настоящий API: тестовый сценарий читает серверные ключи и задаёт длительности только собственным временным записям. Это проверка программного сценария выдачи сертификата, **не аттестация человека**.

На странице двойника показан вариант «ответ за один день, два этапа интервью». Изменения относятся к модели и не переписывают профиль. Проценты на кривой и сроки не являются калиброванными вероятностями реального найма.

[`capture.json`](assets/screenshots/capture.json) содержит время, версию браузера, маршруты без адреса частного стенда, размеры viewport, SHA-256 каждого файла, отпечаток веб-исходников и результаты проверки ошибок. Обложка [`cover.svg`](assets/cover.svg) — отдельная векторная иллюстрация продуктового пути.

## Обновление прежних изображений

Проверка старого набора выявила семь устаревших кадров входа: `auth-access-{390,768,1440}.png`, `auth-revision-{390,768,1440}.png` и `demo-revision-logout.png`. Они показывали прежний заголовок «Найдите команду, которая ищет вас». Во всех текущих копиях эти файлы заменены новыми снимками с заголовком «Те самые люди. Та самая работа».

Дополнительно заново сняты остальные 30 изображений интерфейса приложения в [`validation/reports/current/`](../validation/reports/current/): вход, доказательства обеих ролей, статусы допуска, двойники, граф и исследовательские кабинеты. Для них повторены соответствующие браузерные проверки, включая шесть языков и мобильные размеры. Изменение данных тестового профиля или фазы анимированного фона само по себе не считалось признаком устаревшего интерфейса.

Исходные JSON-протоколы и хеши прежних PNG сохранены в [`archive/2026-10-10-login/`](../validation/reports/archive/2026-10-10-login/) и [`archive/2026-10-10-ui/`](../validation/reports/archive/2026-10-10-ui/). Сами старые изображения доступны в истории Git. Сводный протокол обновления: [`screenshot-refresh.json`](../validation/reports/publication/screenshot-refresh.json).

Десять изображений страниц PDF и один снимок Grafana сохраняют роль датированных материалов соответствующих проверок. Они не входят в продуктовую галерею. В PDF-досье изображения интерфейса не встроены: схемы и графики представлены векторными элементами. Нагрузочные и численные испытания при обновлении кадров не повторялись; даты исходных измерений сохранены.

## Повторная съёмка

Нужна подготовленная демонстрационная установка с `FSP_DEMO_MODE=true`, действующей конфигурацией `.env`, БД, работающими API и worker. Сценарий допускается только на демонстрационном стенде, поскольку создаёт временные тестовые записи. Адрес и секреты не публикуются.

```powershell
.\.venv\Scripts\python.exe -m pip install playwright
.\.venv\Scripts\python.exe -m playwright install chromium
.\.venv\Scripts\python.exe scripts/capture_readme.py
```

Если конфигурация работающего стенда находится в другом checkout, передайте `--runtime-root C:\path\to\proofit`. Снимки записываются в репозиторий, содержащий сценарий съёмки. После изменения интерфейса повторите съёмку, проверьте подписи и обновите отчёт. Браузерный сценарий завершает работу с ошибкой, если обнаружит видимый блок ошибки, сбой JavaScript, неудачный сетевой запрос или горизонтальное переполнение.
